# `migrations/versions/20260408_0001_init_v1_schema.py` 解释文档

## 文件与定位 (Overview & Purpose)
这是一份由 Alembic 生成的具体关系库版本迁移快照执行文件。也就是经常在开发提到的“第一版”数据库升级补丁。

## 核心内容与设计

### 版本元数据记录标识
在顶部利用了内置变量将本次升级命名记录为 `revision = "20260408_0001"` 并标识没有前面的历史依赖 `down_revision = None`。

### 1. `upgrade()`
正向推进数据库建立操作函数。在这里被翻译为一组连续利用 Alembic `op` (Operations) 库跑出的实体创建命令。
- 先依次构建五张表的具体主键，格式规范等 (`storage/models.py` 中写明的表结构这里直接被转译成 `create_table` 建立 MySQL 结构的脚本)。
- 生成与该表主键或者复杂关联对应的专用检索索引 (`op.create_index(...)`) 例如对于时序密集拉取的表按发生事件的字段进行创建索引以提高后期调表速度。

### 2. `downgrade()`
版本撤销退回的悔棋解药回退函数。
执行纯干掉该修改库造成的全影响倒序：在系统想退回到这之前的时，由于上文全部为建立（`CREATE`），这里即由小表到大表逆向全清索引 (`drop_index`) 然后再执行推平删除全物理表的数据与结构 (`drop_table`)。该步骤保证所有迁移能被无副作用还原。
